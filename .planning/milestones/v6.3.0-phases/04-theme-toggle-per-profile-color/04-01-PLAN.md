<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| chrome.storage.sync → applyTheme | `visualMode` value from sync storage (possibly from another device/profile) reaches DOM attribute setter |
| localStorage → theme-init.js | Pre-paint cache written by extension pages read synchronously by `theme-init.js` on next load |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | applyTheme(mode) — data-theme attribute | mitigate | `if (mode === 'light' \|\| mode === 'dark')` guard; any other string (including a crafted `visualMode` injection from a compromised sync account) falls to the else branch which calls removeAttribute — no setAttribute with an attacker-controlled string |
| T-04-02 | Spoofing | localStorage['visualMode'] — pre-paint cache | accept | Extension pages share the extension origin's localStorage partition, isolated from web pages; no cross-origin write path exists; the validate-on-read pattern in theme-init.js provides additional defense |
| T-04-SC | Tampering | npm/pip/cargo installs | accept | No new packages installed in Phase 4 — zero supply chain surface |
</threat_model>
