Read bin/build.sh in full first. Current content (36 lines):

  browsers=("chrome" "firefox")
  for brw in ${browsers[@]}
  do
    \cp src/js/content.js dist/$brw/js/
    \cp -r src/js/war dist/$brw/js/
    \cp -r src/*.html dist/$brw/
    \cp -r icons  dist/$brw/
  done

Add EXACTLY these two lines inside the for loop, after the \cp -r icons line and before `done`:

    \cp -r src/css dist/$brw/

The -r flag on src/css copies the whole css/ directory (creating dist/chrome/css/ and dist/firefox/css/ with all .css files inside). The -f flag on theme-init.js forces overwrite if it somehow already exists. The backslash prefix (\cp) matches the existing convention in the file (bypasses cp aliases).

Do NOT change any other line. Do NOT add a rollup call. Do NOT change the loop structure or the echo. This is a 2-line addition only.

After editing, the loop body should be:
    \cp src/js/content.js dist/$brw/js/
    \cp -r src/js/war dist/$brw/js/
    \cp -r src/*.html dist/$brw/
    \cp -r icons  dist/$brw/
