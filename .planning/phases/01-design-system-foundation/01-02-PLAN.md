  <name>Task 1: Create src/js/theme-init.js (pre-paint engine)</name>
  <files>src/js/theme-init.js</files>
  <action>
Create src/js/theme-init.js as a plain non-module script (no "use strict", no `export`, no `import`, no IIFE wrapper required — synchronous top-level statements are fine for a pre-paint script).

The AUTHORITATIVE logic is from UI-SPEC §2 (not the PATTERNS.md IIFE variant):

  var m = localStorage.getItem('visualMode');
  if (m === 'light' || m === 'dark') {
    document.documentElement.setAttribute('data-theme', m);
  } else {
    document.documentElement.removeAttribute('data-theme');
  }

This is the complete file content. Do NOT add matchMedia fallback, do NOT add event listeners, do NOT add IIFE wrapper. The allowlist check (m === 'light' || m === 'dark') is critical: 'default', null, or any other value must hit the removeAttribute branch so the CSS @media OS-dark branch can take over. No other logic belongs here — Phase 4 owns the write-through and live-update.

Storage contract note (do NOT implement in this file):
- localStorage['visualMode'] = same-device pre-paint cache (read here)
- chrome.storage.sync['visualMode'] = cross-device source of truth (Phase 4 — not this file)
The key is 'visualMode' (not 'aesr.visualMode', not 'theme').

CSP note: This file is served as an external script via src="js/theme-init.js" — this is MV3/MV2-safe. No inline script is added to any HTML file. Do not add a 'nonce' or change content_security_policy in any manifest.
