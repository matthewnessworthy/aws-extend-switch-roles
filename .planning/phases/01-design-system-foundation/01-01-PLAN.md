   - Inputs: text input (.aesr-input), textarea (.aesr-textarea), select (.aesr-select)
   - Controls: checkbox (.aesr-checkbox), radio (.aesr-radio)
   - Role-list item shell (.aesr-role-item): contains account-id span (.aesr-role-item__account) and role-name span (.aesr-role-item__name)
   - Pane/container shell (.aesr-pane)
   - Divider (.aesr-divider)
   - Empty-state shell (.aesr-state-empty): heading slot (.aesr-state-empty__heading) + body slot (.aesr-state-empty__body)
   - Loading-state shell (.aesr-state-loading): body slot (.aesr-state-loading__body)
   - Error/alert shell (.aesr-alert .aesr-alert--error): heading slot (.aesr-alert__heading) + body slot (.aesr-alert__body)
