Per-page instructions:

--- src/popup.html ---
Current state: no DOCTYPE, no charset meta, inline <style> starts early in <head>, module script in <body>.
Required changes:
1. Add <!DOCTYPE html> as the very first line (before the existing <html> tag)
2. Add <meta charset="UTF-8"> as the first child inside <head>
3. Insert the 4-line theme-init + CSS block IMMEDIATELY after the <meta charset> line and BEFORE the existing <style> tag. Source order matters: the inline <style> must remain AFTER the <link> chain (this is what gives it cascade priority over base.css — the D-02 insulation mechanism). Do NOT move or remove the existing <style> block.
Indent style: match whatever indent is in the existing <head> (inspect the file first).

--- src/options.html ---
Current state: has DOCTYPE + charset; first child of <head> is <script type="module" src="js/options.js">.
Required change:
Insert the 4-line block as the FIRST child of <head>, BEFORE the existing <script type="module" src="js/options.js"> line.
theme-init.js must be BEFORE the module script because the pre-paint script must run before any deferred/async module execution could theoretically change the DOM.
Indent style: 4 spaces (match existing).

--- src/supporters.html ---
Current state: has DOCTYPE + charset; existing <head> has no script.
Required change:
Insert the 4-line block after the <meta charset> line (or after <title> if that's the first child — inspect the file first to determine the correct insertion point after the last existing head meta). The block should come before any existing <style> if present.
Indent style: 4 spaces (match existing).

--- src/credits.html ---
Current state: has DOCTYPE + charset; <head> has <title> and a <style> block; no script.
Required change:
Insert the 4-line block after the <meta charset> line and BEFORE any <style> tag. The insertion order in the file must be: charset → theme-init script → CSS links → existing <style> (if any). Same source-order insulation logic as popup.
Indent style: 2 spaces (inspect the file first).

--- src/updated.html ---
Current state: has DOCTYPE + charset; <head> has no script.
Required change: same as supporters.html — insert 4-line block after <meta charset>, before any existing <style>.
