  <action>
    1. npm run build
       Rebuilds dist/chrome/ and dist/firefox/ from src/. This will include options.css and pages.css which were missing from the stale dist/ (Pitfall 3 in RESEARCH.md).

    2. npm run archive
       Produces store zip files in dist/.

    3. Verify the build output:
       ls dist/chrome/css/ — expect all 6 files: tokens.css, base.css, components.css, popup.css, options.css, pages.css
       ls dist/firefox/css/ — same 6 files

    4. Verify the manifest diff (no new permissions or hosts):
       git diff v6.2.1 -- manifest.json manifest_chrome.json manifest_firefox.json
       The output must be empty. If non-empty, stop and investigate before proceeding.

    5. Verify archive sizes:
       wc -c dist/chrome/*.zip dist/firefox/*.zip
       Both must be well under 131072000 bytes (128MB store limit). Expect ~100-120KB.

    6. Create the AMO source zip in the project root:
       zip -r aesr-source.zip src/ package.json package-lock.json rollup.config.js bin/ manifest.json manifest_chrome.json manifest_firefox.json BUILD.md
       Note: run this AFTER writing BUILD.md (step 7) so BUILD.md is included.

    7. Create BUILD.md in the project root with this content:
       Section "## Build Environment":
         - Node.js >= 20.19.0 (CI uses Node 24)
         - npm (lockfile: package-lock.json)
       Section "## Steps":
         npm ci
         npm run build
         # Output: dist/chrome/ and dist/firefox/

         npm run archive
         # Output: dist/chrome/aesr-chrome-*.zip, dist/firefox/aesr-firefox-*.zip
       Keep it minimal — this is the AMO reproducibility doc, not a general README.

    Final order: build → archive → verify → write BUILD.md → zip source.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm run build → dist/ | Build reads only src/ and bin/; output is deterministic from committed source |
| Store zip → store review | Extension bundle contains no new permissions; manifest diff is empty vs v6.2.1 |
| AMO source zip | Contains only committed source code — no secrets or credentials |

## STRIDE Threat Register

| T-05-03-02 | Information Disclosure | AMO source zip | accept | Source zip contains only extension source code — no secrets, credentials, or .env files; BUILD.md contains only public build steps |

</threat_model>
