<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm run build → dist/ | Build reads only src/ and bin/; output is deterministic from committed source |
| Store zip → store review | Extension bundle contains no new permissions; manifest diff is empty vs v6.2.1 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03-01 | Tampering | dist/ build output | accept | Build is deterministic from committed source; git diff confirms manifest is clean; no new permissions |
| T-05-03-02 | Information Disclosure | AMO source zip | accept | Source zip contains only extension source code — no secrets, credentials, or .env files; BUILD.md contains only public build steps |
| T-05-03-03 | Tampering | npm run archive zip integrity | accept | Archive script produces store zips from dist/; no code signing or injection path beyond committed source |
</threat_model>
